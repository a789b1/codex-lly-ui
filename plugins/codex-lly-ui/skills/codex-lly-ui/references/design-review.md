# 设计复核：用判断改进画面

## 实现前
用相同真实内容比较候选：最长标题、空结果、主要操作和关键状态必须可比。
记录每个方向的任务收益、代价和手机重排；选择理由引用具体画面，不用审美打分。
已有产品先尊重其视觉系统，不为了差异强加新字体、装饰或卡片。
完整页面先做代表性片段并以原尺寸看图，再推广到全页。

## 实现后
逐项写“观察 → 问题 → 修改 → 复查证据”，没有问题可记录具体观察：
- 层级：第一眼看到什么，主操作是否能识别；次要信息是否抢占注意。
- 内容：长名称、多位数字、空数据与真实文案是否保持阅读顺序。
- 字体：实际字号与对比度是否足够；不能仅放大截图检查。
- 构图：间距和对齐是否一致；装饰是否帮助理解，是否挤压任务。
- 窄屏：重排后的首屏优先级、换行、点击区域、弹窗和键盘焦点。
- 状态：错误、成功和进行中是否明确，文案是否暗示不存在的后台能力。

至少查看桌面整体、手机整体和主要交互状态。自动检查、像素一致都不能代替这些判断。
交付列出最重要的取舍和未解决项；执行者自查不能称为独立评审。
