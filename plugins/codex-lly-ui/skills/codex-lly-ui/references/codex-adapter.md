# Codex 调用说明

## 保留设计方法，替换宿主接口

主流程与 14 个设计参考分册来自 MIT 开源 Oil UI 0.24.2（DSH 插件也使用此技能）。保留方向探索、标杆拆解、视觉语言、素材、动效、滚动叙事和独立评审，不用短检查表替代它们。用户指定参考和改动范围时直接沿用，不自行重做产品结构。

`<skill>` 指当前实际加载的 SKILL.md 所在绝对目录。从宿主提供的技能路径取得，不猜版本号。所有产物写到用户项目，不能写入安装目录。先用 `lly_ui_status` 读取实际服务版本；安装成功与当前会话已加载新版是两件事。

## 调用对应关系

| 任务 | Codex 中的入口 | 边界 |
| --- | --- | --- |
| 原设计流程、方向卡 | 本 SKILL 和 references；`lly_ui_brief` 可保存约束 | 文档不是视觉证明 |
| 可交互候选比较 | `python3 <skill>/scripts/build_explorer.py --help`，按 [比较页](style-explorer.md) 的 manifest 生成 | 需要 Python 3.10+；URL 候选需开发服务器 |
| 快速候选截图比较 | `lly_ui_explorer` | 只展示截图，不可假称可交互 |
| 状态、局部、200% 放大、录屏与动效 | `node <skill>/scripts/shoot.mjs --help`，按 [工具](tools.md) 执行 | Node 22+，Chrome；录制功能以实际运行结果为准 |
| 可断言的操作与刷新恢复 | `lly_ui_capture` | 必须检查 assert 结果，点击成功不等于业务成功 |
| 无障碍、多视口、像素回归、报告 | `lly_ui_audit`、`lly_ui_baseline`、`lly_ui_report` | 通过不等于设计优秀 |
| 生图、网页调研、登录态操作 | 当前 Codex 可用的原生工具与用户指定浏览器 | 不假定 DSH 工具存在，不使用额外收费接口 |
| 素材检索与加工 | `curate-media.mjs`、`prep-image.mjs`，先运行 --help | 保留素材许可；lly_ui_assets 仅登记来源 |

设计参考中的脚本路径实际随包提供，不把 `shoot` 的高级参数硬翻译成不支持它们的 MCP 参数。优先按宿主要求使用浏览器；本地截图脚本用于自己生成的页面和隔离取证。

## 评审与交付

Codex 不会自动向评审者注入手册。需要独立评审、且宿主允许时，显式提供 reviewer-manual.md 或 ux-reviewer.md 的绝对路径、页面地址、目标视口、任务及约束。不把制作历史和自评分数当作审稿依据。没有独立执行者时标注自检，不冒充独立评审。

保留上游的设计评审深度；项目要求的构建、测试仍须执行，不因技能的精简测试建议跳过项目必需检查。最终展示可运行页面与实际截图，说明生成环境、模拟数据和未完成项。不能把上游作品截图标为 Codex LLY UI 作品，也不能把旧版本页面标为新版方法产物。
