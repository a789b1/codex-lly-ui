# 帧间 · 设计决定

## 选择 B：单张检视

北极星：一次把一张照片看清楚，让决定紧贴照片，其余照片保留连续上下文。

品类与任务：摄影选片工作台，主要操作是判断当前照片是否值得留下。真实参考截图及拆解见 research/NOTES.md。三个候选共用 8 张照片、同一相册和初始空选片状态，真实截图见 evidence/directions/sheet.png，可打开 directions/style-explorer.html 比较。

- A 接触印样：扫视效率高，但常见后台侧栏和三列网格占主导，缩略裁切不适合判断完整摄影构图。
- B 单张检视：完整大图占主区，决策紧邻，底部所有照片维持上下文；最符合逐张选片任务，选定。
- C 策展墙：错落图幅与空间节奏鲜明，适合展示作品；对等地比较摄影构图时，图幅不同会造成偏向。

三者骨架、色相与主视觉组织不同，不是换肤。最终以 B 为底稿；保留 A 的总览效率为可切换视图，不混合三套视觉语言。候选中 C14 实为警告牌，与瀑布题材不符，查看真实截图后替换为 C8 雪中瀑布。

## 最终方向卡

- 生成引擎：摄影编辑的检视台。图像完整展示，色彩判断优先，不模拟实体器材道具。
- 调性：安静、精确、中密度、轻控件、庄重；用于持续判断摄影，不作营销展示。
- 结构：66px 导航，96px 相册与筛选；主区为完整大图 + 292px 决策信息；下方八图胶片带与保存状态。手机变单列，主图与选片先出现。
- 字体：系统 sans 14px 操作/正文；宋体 26px 相册标题；等宽 11–12px 编号与设备无关的工具提示。照片名 28px，不将正文压成小字。
- 色彩：画布 #18232D、观察区 #101B24、信息区 #202E39、正文 #EDF2F4、辅助 #A8B9C5、动作 #B0DADD。青灰来自海岸空气，界面降低饱和度，不给照片加滤镜。
- 图标：不引入整套装饰图标，用必要字符和文字；只有来源外链使用 ↗，导出为向下箭头。
- 控件：4–5px 圆角、1px 边框；入选按钮和缩略选中共享冰川青，已入选有勾号，不只变色。
- 记忆点：主图中的山脉倒影，下面横向地貌序列；入选后缩略图盖上一枚小勾章，真实计数跟随变化。
- 动效：“咔嗒，选片标记落位”。主图初次 400ms 轻淡入，勾章 250ms 小幅吸合，大图 220ms 打开；按钮 120ms 按压。减少动态效果时全部直接到位。
- 放弃：营销大标题、统计卡片、虚构账户头像、未实现导入、云同步承诺、装饰性循环、无意义拍摄参数。
- 减法：删掉候选“让每一帧值得留下”口号、导入入口、虚构账户、跳过与下一张重复入口；把“所有更改已保存”替换为实际保存状态。

## 功能与边界

真实实现：分类/搜索、全部/入选、总览/单张、大图、键盘切换、入选、笔记、刷新恢复、失败重试、带摄影来源的 JSON 导出。照片 ID 和中文标题为编目用名；摄影原作者、原片尺寸与许可来自来源记录。选片存在浏览器，不上传。没有登录、客户审片或云端后端。

## 独立评审后的修正

第一轮视觉评审指出平板照片面积不足、手机前置工具过高和决策远离照片。改为 1000px 以下完整宽度检视，入选与标题并排；笔记和来源可展开；手机顶栏压成单行，保留全部关键功能。手机主图起点由约327px提前到约207px，平板主图由约364×244扩大到约574×383（截图可核对）。独立 UX 发现手机点缩略图后不返回大图，已改为滚回检视区并保持键盘焦点。

最终独立静态评审为8/10；不是客观性能指标。进一步加强手机当前缩略图的双像素轮廓。保留桌面主图与八张邻片同屏的取舍，不为继续扩大一张图把整条序列推出首屏。保留小型项目字标以识别作品，不新增品牌模块。动态另通过真实操作录像检查，静态评审不冒充动效验收。
