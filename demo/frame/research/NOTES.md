# 标杆研究

实际访问并截图：
- https://pixieset.com/client-gallery/ （公开介绍）
- https://withluke.pixieset.com/visitsaudixwithluke/ （真实画廊，进入 VIEW GALLERY 并打开照片）
- https://picflow.com/ 与 https://picflow.com/client-gallery/ （产品介绍与画廊入口）
- https://demo.picflow.com/nnormal （实际画廊）

保留的是产品关系，不复制页面代码或照片：
1. Pixieset 画廊标题与操作合为一行，照片从紧接页头的位置开始；用户来挑照片，不需要再看广告式大标题。
2. 画廊采用窄间隙瀑布流，图片本身提供颜色和密度；照片不再套白卡片和阴影。
3. 深中性背景不与照片色彩竞争；选片也需要中性工作区，不能给照片统一滤镜来配合 UI。
4. 查看大图沿用所点击的图像，建立空间连续；返回保留浏览位置。
5. 收藏标记放在图内，能对准当前对象；帧间改用持续可见的入选控件，避免移动端缺少悬停。
6. 下载、收藏等集合动作放在右上；帧间用明确文字“导出清单”，不让下载图标暗示下载全部原片。
7. 摄影页面减少界面色相，把视觉预算交给内容；帧间只用一种状态强调色。
8. 营销页的大标题和 CTA 不搬进选片工作台；只借其图片质量、字级与控件一致性。

UI/UX Pro Max 首次检索返回的是营销页滚动叙事，不适合选片任务；已弃用。针对照片选择的 UX 检索没有命中，不将其输出当成本次设计依据。具体视觉决策以实际参考和 Oil UI 流程为准。
