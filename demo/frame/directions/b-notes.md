# B · LOUPE / 凝视选片

- 北极星：一次把一张照片看清楚，让决定紧贴照片，让其余照片成为连续的上下文。
- 生成引擎：摄影编辑的单张检视台；放大当前照片、底部连续胶片带，不仿制实体器材。
- 首屏骨架：64px 全局导航 + 91px 相册栏；546px 检视区（左大图、右 282px 决策信息）；166px 八张胶片带；33px 快捷键状态栏。无侧栏、无卡片网格。
- 字体：系统 sans-serif 负责 UI，正文 13px、标签 10–11px；相册标题 Georgia / Songti SC 25px，少量衬线为相册增加编辑感。
- 色彩：底色 #18232D；检视底 #111C25；详情底 #202D38；冰川青 #A8D5D6 仅用于选片动作与当前缩略图；边框 #34434E；正文 #E4E9ED；弱文本 #9EAFBB。青灰取自海岸空气与冰岛远山，弱化工具界面的色彩干扰。
- 主视觉：C10 Vestrahorn 海岸原图完整显示，以 762 × 508 占据观察区；图片不承担营销背景，操作和信息均在外侧。
- 控件：4px 圆角，1px 边框；当前缩略图用冰川青细线定位。简短文字和几何符号，无第三方图标依赖。
- 记忆点：深青灰观察台上完整的山脉倒影，下方八张连续地貌缩略图像一条视觉句子；当前照片与加入选片按钮用同一抹冰川青呼应。
- 取舍：优先逐张判断，弱化批量总览；不加左侧栏、统计卡片、首屏宣言。静态首屏仅表达布局，不包含交互、动画或响应式实现。
- 调性：安静、精确、中等密度、轻控件、庄重；依据为摄影筛选需要低干扰与持续查看。
- 标杆与取舍：参照任务共享研究；本方向保留摄影软件单张检视和缩略序列的基线，改用蓝灰与冰川青的内容色彩身份。
