# C · 展墙 Gallery Wall

- 北极星：像在策展桌前比较照片，以不同尺度读出地貌之间的关系，同时随手完成筛选与导出。
- 生成引擎：摄影展墙的错落悬挂；借用图幅比例和底线对齐，不复制画框或展签道具。
- 首屏骨架：无侧栏；一行品牌导航、一行相册与筛选，三个不同尺度的重点图像，下方五张支撑照片。8 张照片完整出现在 1440 × 900 首屏。
- 字体：Songti SC 28px 相册名、19px 主图名、15px 缩略图名；PingFang SC 12px 工具文字；10px 等宽序号形成轻量编目感。
- 色彩：冷淡紫 #f0eef5 底色，梅紫 #332a3d 正文，#493354 主操作，#79558d 筛选标记，#d4cfdd 分隔线，#9b8fa5 辅助文字。冰岛阴天与冰雪的冷色环境适合略带紫调的空间底色，避免暖纸色干扰图像冷暖比较。
- 主视觉：前三张照片形成大小不等、底部齐平的展墙；其余照片以横向目录呈现。照片均复用 shared.json 指定素材。
- 控件：主按钮 3px 圆角，1px 细描边，照片右上圆形选择框；紫色仅用于主动作与当前筛选。初始已选 0 张。
- 结构性突破：打破均匀联系表与固定侧栏，以图像尺度差异帮助横向比较构图和题材。
- 取舍：更适合精选小相册；大规模初筛时，同尺寸网格效率更高。
- 静态方向样稿，无脚本、动效、响应式行为。
